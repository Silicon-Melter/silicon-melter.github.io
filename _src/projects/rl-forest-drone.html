Reinforcement-learning forest drone

2023 · Python, Stable Baselines3 (PPO), AirSim, 3D Gaussian Splatting

A drone that learned to fly from point to point through a forest by trial and error in simulation.

Add a screenshot of the simulated forest here.

  • A navigation agent trained with Proximal Policy Optimization (PPO), a reinforcement learning method, in a custom AirSim environment.
  • Standard simulators draw trees and obstacles too simply. 3D Gaussian Splatting, which rebuilds real scenes from photos, gave the agent more realistic obstacles to learn from.
