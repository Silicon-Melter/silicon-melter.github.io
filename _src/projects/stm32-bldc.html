STM32 BLDC motor controller

2024 · C (STM32 HAL), FOC, SPI, Modbus RTU over RS485, Python

A brushless motor controller built from the ground up: the control maths on a microcontroller, a custom circuit board, and a desktop app to watch it run.

Add a photo of the PCB here.

  • Field-oriented control (FOC) on an STM32, with an AS5048A magnetic encoder read over SPI for rotor position and speed.
  • A Python GUI talking Modbus RTU over RS485, with the CRC16 checksum written by hand, for industrial-style telemetry.
