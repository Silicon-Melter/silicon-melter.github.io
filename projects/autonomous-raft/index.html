Sensor fusion and drive-by-wire for an autonomous raft

2025 · C++, Python, ROS 2, EKF, MAVROS, Arduino, UART, PID

On water, currents push a boat sideways all the time. This project gave a small unmanned raft a reliable sense of where it was and which way it pointed, and used that to hold its course.

Add a photo of the raft here.

What I built

  • State estimation. An Extended Kalman Filter, run through MAVROS, fuses GPS position with a 9-axis IMU's orientation.
  • Heading-assisted control. Two PID loops regulate forward speed and yaw separately, so when the operator steers, the raft corrects for currents automatically.
  • Drive-by-wire. An Arduino drives the motors from commands sent over serial.
