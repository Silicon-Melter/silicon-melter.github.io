Autonomous indoor drone without GPS

2025 · C++, ROS 2 Humble, PX4 Autopilot, MAVROS, Gazebo, Raspberry Pi

Indoors there is no GPS, so a drone has to know where it is from its own sensors. This drone flew autonomous missions using optical flow for position.

Add a photo or a short flight video here.

What I built

  • A ROS 2 offboard control node that arms the drone, switches PX4 into offboard mode and runs the mission.
  • A trajectory generator that reads waypoints from a CSV file and streams TrajectorySetpoint messages to the PX4 flight controller over the micro-ROS XRCE-DDS bridge.
  • Testing in Gazebo simulation first, then on the real drone with a Raspberry Pi companion computer.
